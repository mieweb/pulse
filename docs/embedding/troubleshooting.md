# Troubleshooting

Find the code from the `PulseError` your call rejected with (`e.code`), or from a `failed` result
(`result.error.code`). Every error carries a `callId`; search PulseKit's `[PulseKit]` log lines for
it ([dev-loop.md](dev-loop.md#logs)). [contract.md](contract.md#errors) lists every code.

## Pulse doesn't open

| Code or symptom                                    | Cause                                                                                                                                                                              | What to do                                                                                                                                                                   |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `unavailable`                                      | The page has no Pulse plugin: a desktop browser, a web build, or the plugin isn't installed or synced.                                                                             | Show your fallback (a link or QR code). In the app, check that the plugin is in `package.json` and that `npx cap sync ios` or `cordova prepare ios` ran after installing it. |
| `unsupported`                                      | `getInfo().supported` is false: iOS before 16.4, an iPad, a Mac, or Android.                                                                                                       | Show your fallback. `getInfo().unsupportedReason` says which: `os`, `ipad` or `device`.                                                                                      |
| `failed` with `unsupported` right after `record()` | `configure()` wasn't called with `uploadMode: 'file'`, so the default `'pulse'` applies, which this version can't do.                                                              | Call `configure({ uploadMode: 'file' })` once per page load, before the first `open`.                                                                                        |
| `contract.unsupported`                             | The client and PulseKit have different contract majors.                                                                                                                            | Install the same exact version of `@mieweb/pulse-embed` and the plugin.                                                                                                      |
| `method.unsupported`                               | This PulseKit doesn't list the method in `getInfo().methods`, for example `listDrafts`.                                                                                            | Check `methods.includes(name)` before calling, and hide the feature when it's missing.                                                                                       |
| `busy`                                             | A flow is already open with another `requestId`, or your app is presenting a screen (an alert, a sheet).                                                                           | Wait for the open flow's result, or dismiss your own screen first. To join the open flow instead, call `open` with its `requestId`.                                          |
| `invalid_options`                                  | A field is missing or has the wrong type: often `context` without `label`, a `contextKey` with characters outside `[a-z0-9._-]` for the kind, or a `context` over 8 KB.            | Read `e.message`; it names the field. Build `key` with `contextKey(kind, id)`.                                                                                               |
| `host_misconfigured`                               | Your app's `Info.plist` lacks `NSCameraUsageDescription` or `NSMicrophoneUsageDescription` (`e.details.missing` lists them), or the plugin had no view controller to present from. | Add the keys ([host checklist](README.md#host-checklist)) and rebuild. Opening Pulse before your app's first screen is up can also cause it.                                 |
| Save to Photos is missing on Export                | `NSPhotoLibraryAddUsageDescription` isn't in your `Info.plist`, or `policy.allowSaveToPhotos` is false.                                                                            | Add the key, or remove the policy.                                                                                                                                           |
| A second `flowResult` for the same `requestId`     | PulseKit ended the flow itself (your `close()` got no answer in 5 s, or your app dismissed Pulse), then Pulse's own result arrived.                                                | Expected. Act on the latest result, and make handling a `requestId` twice harmless.                                                                                          |
| No result after a page reload                      | The `open` promise belonged to the old page.                                                                                                                                       | Call `pendingResults()` on every page load and handle what it returns.                                                                                                       |

## The flow ended `failed`

| Code              | Cause                                                                                                  | What to do                                                                                                                                                           |
| ----------------- | ------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `not_found`       | `edit` or `export` named a draft that doesn't exist on this phone.                                     | Drop your reference to that draft.                                                                                                                                   |
| `storage.full`    | The phone is out of space. Pulse said so and kept the videos.                                          | Ask the person to free up space, then open Pulse again.                                                                                                              |
| `storage.damaged` | Pulse couldn't open or update its library on this phone.                                               | Report it with the `callId` and `logFile()`. `error.details.reset: true` means the person tapped Reset; this version deletes nothing, so the library is still there. |
| `export.failed`   | After "Use this video", Pulse couldn't copy the video out for your app. The draft is kept (`draftId`). | Open it again with `exportDraft(draftId)`; if it fails again, report it with the log.                                                                                |
| `runtime.error`   | A JavaScript error inside Pulse. Your app keeps running.                                               | Open Pulse again; the next `open` starts a fresh runtime. Report it with `logFile()` and the crash's source map ([releasing.md](releasing.md#symbolicate-a-crash)).  |

## Codes for later versions

This version never sends these; they are in the types so you can handle them now. What they will
mean:

| Code                | Meaning                                                                                                                         | What to do                                                                                      |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `no_account`        | A drafts or upload call before `setAccount()`, or after `setAccount(null)`.                                                     | Call `setAccount()` on sign-in and on session restore, before the first read.                   |
| `restart_required`  | `setAccount()` for a different person after Pulse's runtime had started in this app session.                                    | Ask the person to restart the app; reads for the new account still work until then.             |
| `host.unavailable`  | A host service (`getUploadTarget`, `refreshUploadToken`) didn't answer within 20 s.                                             | Make sure `setHostServices()` runs on every page load, and that its handlers resolve or reject. |
| `needs_credentials` | A draft state, not an error: an upload's token expired and your app didn't supply a new one (signed out, or no answer in 20 s). | Pulse retries once your app answers again; after sign-in, call `resumeOutbox()`.                |
| `runtime.paused`    | Your server paused PulseKit (the kill switch).                                                                                  | Show that Pulse is unavailable for now; unsent drafts stay on the phone.                        |
| `draft.locked`      | The draft is uploading, sent, or open in the current flow.                                                                      | Wait for the upload, or close the flow.                                                         |
| `timeout`           | Pulse's runtime didn't answer a forwarded call within 30 s.                                                                     | Retry; `createPulseClient({ timeoutMs })` raises the limit.                                     |
