# cordova-plugin-pulse

The Cordova plugin `Pulse`: the native transport between `@mieweb/pulse-embed` and PulseKit, for
cordova-ios 8 or later. It passes JSON requests and replies through unchanged and delivers
PulseKit's events to your page. It holds no Pulse logic; your page calls Pulse through
`@mieweb/pulse-embed`, never this plugin directly.

Setup steps are in the Pulse repo's [docs/embedding/cordova.md](../../../docs/embedding/cordova.md).

```sh
npm install --save-exact @mieweb/pulse-embed@rc
npx cordova plugin add cordova-plugin-pulse@rc
```

## Platforms

- **iOS:** `PulseKit.podspec` downloads `PulseKit-xcframeworks.zip` from the PulseKit GitHub
  Release and checks its SHA-256. Pulse runs on iPhone with iOS 16.4 or later.
- **Android:** a stub. It adds no permissions and no dependencies; `getInfo()` reports
  `supported: false` and every other call answers `unsupported`.

## Files

| Path               | What it is                                                                                                                                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `plugin.xml`       | Declares the `Pulse` feature and puts `www/pulse.js` on `window.PulseKit`.                                                                      |
| `www/pulse.js`     | `call(json)` and `subscribe(onEvent)` over `cordova.exec`.                                                                                      |
| `PulseKit.podspec` | Generated by `embed/scripts/write-podspec.mjs`. The committed copy is a `0.0.0-dev` placeholder; the release workflow writes the published one. |
| `src/ios/`         | The plugin. It holds `flowResult` events while no page is subscribed and hands them over when one subscribes.                                   |
| `src/android/`     | The stub.                                                                                                                                       |

`PULSEKIT_LOCAL=<folder of *.xcframework>` makes the podspec use a PulseKit you built instead of
the release ([dev-loop](../../../docs/embedding/dev-loop.md#cordova)).

The repo's `embed/hosts/cordova-host` is a test app for this plugin.
